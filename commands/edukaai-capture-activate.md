---
description: Activate EdukaAI capture with a dataset
args:
  dataset: Dataset name or ID (optional)
---

Run this in your terminal (outside OpenCode):

```bash
npx edukaai-opencode on
```

With specific dataset:
```bash
npx edukaai-opencode on my-dataset
```

With dataset ID:
```bash
npx edukaai-opencode on 1
```

This will activate capture.
